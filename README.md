# Callaway Data Watch — Official Website

The main public website for Callaway Data Watch (CDW), a community organization focused on transparency and accountability in local government in Callaway County, Missouri.

This is separate from the [Sunshine Archive](https://archive.callawaydatawatch.org), which is our searchable database of public records. This site is the organization's front door.

## Live site

[callawaydatawatch.org](https://callawaydatawatch.org)

## Pages

- **Home** (`index.html`) — who we are, our mission, and how to reach us
- **Take Action** (`take-action.html`) — what we're working on and how to get involved
- **Videos** (`videos.html`) — embedded video content

## File structure

```
index.html          Home page
take-action.html     Take Action / Get Involved page
videos.html          Videos page
style.css            Shared styling for all pages
assets/              Logo and image files
```

## Making changes

Never push directly to `main`. Create a branch, commit your change, push it, then open a pull request and merge it once reviewed.

```
git checkout -b your-branch-name
git add .
git commit -m "Describe your change"
git push origin your-branch-name
```

Then open a pull request on GitHub and merge once ready.
